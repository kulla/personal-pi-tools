# personal-pi-tools

My personal [pi](https://github.com/earendil-works/pi) tools package.

## Install

```bash
pi install git:github.com/kulla/personal-pi-tools
```

## Extensions

### /commit
Generates an editable conventional commit message from the current pi session and git diff, then stages changes and opens the commit editor.

Usage:
```text
/commit
```
